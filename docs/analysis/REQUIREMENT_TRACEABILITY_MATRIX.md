# 문서-코드 요구사항 추적성 매트릭스

초기 기준 커밋 e21478b. 코드 변경 전 분석 커밋 ab5ed57.

## 집계 기준

총 **196개 추적 행** = UC 15 + US 30 + O 6 + 스프린트 TK 140 + 추가 요구 5. 상하위·중복 태스크를 포함하며 독립 기능 196개라는 뜻은 아니다. UC-01~15 목록은 UC-001~015와 정규화했다. 자리표시자 예시 US-03/TK-01 등은 실제 프로젝트 요구사항에서 제외했다.

- 최초: {'PARTIAL': 123, 'MISSING': 18, 'BROKEN': 1, 'UNVERIFIED': 54} (기존 48개 회귀 테스트는 통과했으나 최신 문서 전체 수용 기준의 완료 증거와는 구분).
- 현재: {'PARTIAL': 65, 'COMPLETE': 78, 'UNVERIFIED': 53, 'MISSING': 0}.
- UC: 9 COMPLETE / 6 PARTIAL. 인수·실DB·물리적 인쇄·모델 정확도까지 완료했다는 뜻이 아니다.

## 문서 조사 및 상충 판단

참고 문서는 Markdown 5개이며 PDF/DOCX/HWPX 원본은 없었다. 파일별 절/원본 줄로 인용하며 가상의 페이지 번호를 만들지 않았다. D02(2026-10-04) 운영계획, D03 v0.1(2026-10-11), D04 v1.01(2026-10-12), D05 9차 현장 피드백 순으로 확인했다. 최신 D04 O-03/O-04/O-06에 따라 AI 직접 채택·상태 완료 자동입고를 최종 확정·검수 완료 기반으로 변경했다.

D02 개발 프로세스 그림과 D03 L68 UC 그림을 임시 파일로 추출해 직접 열람했다. UC 그림은 본문의 15개와 대응하며 추가 미열람 그림은 없다. 참조 원본은 수정/커밋하지 않았다. 문서별 SHA-256과 UC의 정상/하위/예외 흐름 원문은 requirement_catalog.json에 보존했다. D03 문서명 S&P와 D04 SNP 표기는 같은 시스템으로 대응하며 표지 날짜 자리표시자는 개정일로 간주하지 않는다.

D02 연구 패키지 버전과 서비스 환경이 다르지만 AI 모델을 검증 없이 다운그레이드하지 않았다. D05의 과거 완료 표시는 현행 통합 완료 증거로 사용하지 않았다. 조리지시서는 외부 구현 위치를 제공받지 못해 신규 조리 정보 입력과 구분한다.
