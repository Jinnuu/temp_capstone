# 구현 계획 (코드 수정 전)

기준 e21478b의 통합은 완료됐으며 참고 문서만 미추적 상태다. 원본·기존 서비스·AI 모델·참고 문서는 변경하지 않는다.

1. P0: 수동/AI/최종 식수 분리, 0명 포함 입력 검증·확정시점, 변경 시 발주 재검토 표시. 기존 AI 및 업로드 경로 유지.
2. P0: 발주예정 스냅샷·필요량 합산·재고/안전재고·명시 단위 환산·포장 올림·업체/규격 누락 차단·업체별 발주와 중복요청 방지. 날짜별 기존 금요일/주말 규칙 보존.
3. P0: 품목별 납품/합격/불합격·수량차이/유통기한 기록, 실제 합격수량만 입고, 트랜잭션·중복방지. 기존 상태완료만으로 입고하는 우회 경로 차단. 실제사용 출고 부족재고 차단.
4. P1: 업체·카테고리·구조화 납품규격 웹 CRUD, 주간 수불 및 실제 검수 기준 월정산, 업무명 문서와 내비게이션.
5. P1: 단위 있는 레시피·조리 정보, 일간 수정 시 기존 확정/예측 참조 보존, 파일업로드 회귀. 조리지시서는 기존 구현 탐색 후 요구가 충분할 때만 연동.
6. P2: 출력 묶음·정렬·빈 데이터·사용성. FIFO는 정책·기존 lot 미분리 데이터 확인 후 안전한 범위만 구현하고 미완료를 명시.
7. 네트워크 차단 앱/SQLite, 별도 MariaDB socket과 임시 데이터로 check, migration, 기존/신규 테스트, 실제모델 추론, 가능하면 브라우저까지 검증. 모델 정확도/실사용 인수/운영배포는 성공으로 추정하지 않는다.

완료 판정은 실제 실행 증거로 매트릭스에 반영하며 연구·공란·정책미결정 항목은 UNVERIFIED/PARTIAL로 남긴다.
