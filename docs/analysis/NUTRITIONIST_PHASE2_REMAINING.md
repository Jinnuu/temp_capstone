## 현업 정책 확인 및 승인 사항

1. 초과 납품 허용량·승인자·증빙. 새 경로는 초과를 자동 승인하지 않으며 기존 단건 검사의 사유 있는 초과 정책은 그대로다.
2. 확정/수주/출고 이후 취소 마감·업체 동의·독립 승인자. 부분 검수 취소 시 이미 입고된 물품을 자동 역차감하지 않는다.
3. 누적 합격을 기준으로 한 미납 잔량을 공급업체와 합의할 것. 예: 실납105/합격100/불합격5를 실납초과 주문으로 보아야 하는지, 교환으로 종결하는지.
4. 반품 시점·확인자·환불/교환·운송비·공제/세금·정산 마감. 지금의 합격 비례금액은 검토용이며 지급 확정이 아니다.
5. 검수 정정 승인 책임·기한·이미 조리 사용된 lot 보정·정정 취소/재정정 정책.
6. 재발행 문서의 현장 전달·이전본 회수·사용 완료 표시 책임.

새로운 정책이 필요한 항목만 확인 대상으로 분리했다. 기존 계획의 명확한 안전 구현은 후속 단위로 이어갈 수 있으며, 위 전부가 정책 때문에 차단됐다는 의미는 아니다.

## 배포·복구

- 이번 작업에서는 실제 Preview/다른 서비스를 배포·중단·재시작하지 않음. 관리자/비밀번호/공개 가입 정책 변경 없음.
- 실제 DB migration 전 최신 백업 및 격리 복원 검증, 필요하면 신규 기능 노출 제한, 기존 완료 주문 재개 금지 안내, 회차 오류 복구 UX 우선 완료 권장.
- 신규 이력이 있으면0013 역migration이 차단된다. 사용 후 단순 구버전 rollback은 신규 receipt를 읽지 못할 수 있다. 운영 배포 전에 신규 이력을 보존·조회할 수 있는 rollback adapter 또는 forward fix 전략을 마련해야 한다.
- 실제 Preview에 신규 테이블이 없는 상태이므로 현재 공개 서비스에서 신규 화면이 동작한다고 보고하지 않는다. 배포는 사용자 별도 승인 필요.
- AI 변경·실험/재학습·실제 식수/예측 파이프라인 개선은 이번 범위에서 계속 제외한다.
