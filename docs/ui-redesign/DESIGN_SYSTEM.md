# 세 가지 디자인 시스템

| 항목 | MODE 1 레퍼런스형 | MODE 2 그린형 | MODE 3 공공기관형 |
|---|---|---|---|
| 강조색 | 실제 레퍼런스 #e66344 | 사용자 지정 방향 #286447 | #344054 |
| 내비게이션 | 검색 아래 수평 업무 메뉴·드롭다운 | 화면 왼쪽 고정 전체 높이 레일 | 어두운 전체 너비 헤더 + 간결한 왼쪽 목록 |
| 대시보드 | 캘린더 중심, 오른쪽 날짜별 정보 | 요약·업무 정보 먼저, 캘린더 아래 | 날짜별 업무 왼쪽, 캘린더 오른쪽 |
| 제목 | 중앙 큰 제목 | 왼쪽 정렬 | 왼쪽 세로 구분선 |
| 폼 | 라벨·입력 가로 행 | 모델 폼 2열 | 회색 라벨과 정렬된 행 |
| 표 | 작은 패딩·검은 상단 선 | 조금 여유로운 간격·녹색 계층 | 작은 글씨·명확한 회색 경계 |
| 모서리 | 2px | 5px | 0px |

모드는 동일한 백엔드·데이터·업무 버튼을 공유한다. 레이아웃별로 데이터나 기능을 조건부 삭제하지 않는다. 기존 문서의 인쇄 CSS는 유지하고 공통 헤더·내비게이션·모드 선택은 출력에서 숨긴다.

## 공통 사용성

- 현재 선택 `aria-pressed`, 방향키/Home/End, 상태 알림.
- 본문 건너뛰기, 보이는 키보드 포커스, 오류 alert, 성공 status.
- 표 자체와 입력을 유지한 가로 스크롤 region. 중첩 표는 다시 감싸지 않음.
- 960px 이하 메뉴 접기, Escape 닫기, 작업 내용 보존.
- 화려한 그라데이션·카드 그림자 제거, 입력과 조회 결과의 구분선 우선.
- 비교 화면은 실제 동일 데이터의 iframe이며 입력은 비활성화하고 폼 제출을 차단한다. 비교 프레임 모드는 부모의 저장된 모드를 변경하지 않는다.

관리자 페이지는 Django 기본 폼·권한 구조를 유지하며 색상과 공통 모드 선택만 적용한다. 업무 화면처럼 관리자 레이아웃까지 전면 재배치하지 않았다. 접근성은 키보드와 일부 시각 요소를 검증했으며 WCAG 전체 인증 또는 실제 영양사 인수 완료를 의미하지 않는다.
