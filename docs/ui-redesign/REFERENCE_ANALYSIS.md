# 영양사 프로그램 레퍼런스 분석

입력: 사용자가 제공한 `영양사 프로그램.zip` (읽기 전용, Git 제외). PNG 30개 전체의 크기와 색상 분포를 추출했다. 실제 화면을 직접 열어 확인한 대표 6개는 주문목록, 재고등록, 수불리포트, 카테고리 주문, 입고관리, 주문리포트다. 전체 목록·크기·색상은 `verification/ui-three-modes-20261105/reference-analysis.json` 참조.

## 확인한 디자인

- Samsung Welstory DOREMI 업무 화면. 중앙 검색, 수평 업무 메뉴, 흰 배경, 회색 필터 영역, 검은 표 상단 선, 촘촘한 표와 작은 버튼을 사용한다.
- 화면에서 반복되는 대표 주황색 RGB(230,99,68), **#e66344**를 MODE 1에 그대로 적용했다. 브랜드 로고와 실데이터는 복제하지 않았다.
- 검색·조건·조회 결과를 순서대로 배치하고 표 중심 화면을 유지한다. 메뉴 명칭과 URL은 실제 SNP 기능만 제공한다.
- 기존 프로그램의 저대비 흰색/주황색 조합은 주황 배경 위 어두운 글자로 보완했다. 제품을 픽셀 단위로 복제한 것은 아니며 실제 SNP 화면 구조에 맞추었다.

## MODE 2 색상 출처 정정

사용자 확인: “그건 없어. 영양사 프로그램.zip에 대해서 초록색을 적용하라는 소리였어.” 별도 포스터는 존재하지 않는 것으로 확인했다. 포스터 색상 추출·일치 주장을 하지 않는다. 레퍼런스의 업무 구조에 저채도 녹색 **#286447**, 연녹색 **#edf4ef**, 흰색을 적용했다.

원본 ZIP와 추출 이미지는 개인정보 및 실제 거래정보가 있을 수 있어 커밋하지 않는다. 저장하는 화면은 격리 DB에서 만든 QA 데이터만 사용한다.
